# Новая система управления камерой Canon с автофокусом

## 🔧 Основные улучшения

### 1. **Автофокус**
- Автоматическое включение автофокуса при инициализации камеры
- Команда автофокуса перед каждым захватом фото
- Пауза для фокусировки (1 секунда)
- Улучшенное качество изображений

### 2. **Улучшенное управление сессиями**
- Принудительная очистка сессий при инициализации
- Правильная обработка событий отключения камеры
- Уменьшенное время ожидания (15 секунд вместо 30)
- Проверка подключения перед каждым действием

### 3. **Новые команды**
- `force_cleanup_and_reconnect` - принудительная очистка и переподключение
- Улучшенная обработка ошибок
- Более информативные логи

## 📋 Структура Camera

```rust
struct Camera {
    camera_ref: *mut c_void,
    is_live_view_started: bool,
    photo_created: bool,
    is_connected: bool,
}
```

### Основные методы:

- `new()` - Создание с автофокусом и очисткой сессий
- `capture_photo()` - Захват с автофокусом
- `start_live_view()` - Запуск live view
- `stop_live_view()` - Остановка live view
- `download_evf_image()` - Загрузка EVF изображения

## 🚀 Доступные команды

### Основные команды:
```javascript
// Инициализация камеры
await invoke('initialize_camera');

// Проверка статуса
await invoke('check_camera_status');

// Запуск/остановка live view
await invoke('start_live_view');
await invoke('stop_live_view');

// Захват фото с автофокусом
await invoke('capture_photo_as');

// Получение изображения
await invoke('get_captured_image');
```

### Команды восстановления:
```javascript
// Обновление сессии
await invoke('refresh_camera_session');

// Переподключение
await invoke('reconnect_camera');

// Принудительная очистка
await invoke('force_cleanup_sessions');

// Очистка и переподключение
await invoke('force_cleanup_and_reconnect');
```

## 🔍 Обработка событий

### События состояния камеры:
- `0x301` - Критическое отключение
- `0x305` - Временное отключение  
- `0x306` - Подключение камеры

### События объектов:
- `0x208` - Создание файла (захват фото)

## 🛠️ Решение проблем

### Проблема "PC Full":
```javascript
// Способ 1: Через UI
// Нажмите кнопку "Исправить PC Full"

// Способ 2: Через консоль
await invoke('force_cleanup_and_reconnect');
```

### Камера не отвечает:
```javascript
// Принудительная очистка
await invoke('force_cleanup_sessions');

// Переподключение
await invoke('reconnect_camera');
```

### Проблемы с автофокусом:
```javascript
// Переинициализация камеры
await invoke('refresh_camera_session');
```

## 🔧 Конфигурация

### Настройки автофокуса:
```rust
// Режим автофокуса
let af_mode: u32 = 0; // kEdsAfMode_OneShot

// Команда автофокуса
EdsSendCommand(camera_ref, 0x00000004, 0x00010003);
```

### Настройки емкости:
```rust
// Варианты настроек для предотвращения "PC Full"
EdsCapacity {
    number_of_free_clusters: 0x7FFFFFFF,
    bytes_per_sector: 512, // или 1024, 2048, 4096
    reset: true,
}
```
